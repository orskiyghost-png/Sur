# AGENTS.md - Правила для ИИ-агентов

Этот документ содержит инструкции для ИИ-агентов, работающих с проектом Surkove.ru.

## Обзор проекта

**Название:** Surkove.ru - Персональный сайт-портфолио  
**Технологии:** React 19, TypeScript 5.5, Vite 8, Tailwind CSS 4, Framer Motion  
**Хостинг:** GitHub Pages  
**Репозиторий:** https://github.com/orskiyghost-png/Sur.git  
**Домен:** https://www.surkove.ru

## Архитектура проекта

### Структура директорий

```
Sur/
├── src/
│   ├── components/       # Переиспользуемые компоненты
│   │   ├── ui/          # UI-компоненты из ReactBits
│   │   ├── animations/  # Анимационные компоненты
│   │   └── layout/      # Header, Footer, Navigation
│   ├── sections/        # Секции страницы (Hero, About, Portfolio, Skills, Contact)
│   ├── data/            # Данные: проекты, навыки, тексты (отдельно от компонентов!)
│   ├── hooks/           # Кастомные React хуки
│   ├── utils/           # Вспомогательные функции
│   ├── styles/          # Глобальные стили
│   ├── types/           # TypeScript типы
│   └── assets/          # Медиа-файлы (изображения, иконки)
└── public/              # Статические файлы
```

### Ключевые принципы

1. **Модульность:** Один компонент = один файл. Не размещайте весь сайт в App.tsx.
2. **Разделение данных:** Тексты, проекты, навыки хранятся в `src/data/`, не в компонентах.
3. **Чистота кода:** Минимум комментариев. Комментируйте только неочевидную логику.
4. **TypeScript строго:** Избегайте `any`, используйте строгую типизацию.
5. **Не дублируйте:** Перед добавлением библиотеки проверяйте, нет ли аналога.

## Команды

```bash
npm run dev       # Запуск dev сервера (порт 3000)
npm run build     # Сборка проекта (tsc + vite build)
npm run preview   # Предпросмотр production сборки
npm run lint      # Запуск ESLint
```

**Важно:** Результат сборки находится в `dist/`

## Рабочий процесс

### Перед началом работы

1. Изучите существующую структуру
2. Определите, какие файлы потребуют изменений
3. Составьте план реализации
4. Проверьте зависимости

### После изменений

1. Проверьте TypeScript: `npm run build`
2. Проверьте линтинг: `npm run lint`
3. Убедитесь в отсутствии сломанных импортов
4. Проверьте адаптивность на разных экранах
5. Протестируйте анимации
6. Проверьте консоль браузера на ошибки

### Интеграция компонентов ReactBits

При добавлении компонента из ReactBits:

1. Сохраните его работоспособность
2. Адаптируйте стили под дизайн-систему
3. Проверьте и установите зависимости
4. Обеспечьте мобильную адаптацию
5. Проверьте `prefers-reduced-motion`

## Оптимизация

### Изображения
- Используйте WebP/AVIF форматы
- Применяйте lazy loading для галерей
- Оптимизируйте размеры

### Performance
- Не загружайте ненужные библиотеки
- Минимизируйте bundle size
- Используйте code splitting при необходимости

### Accessibility
- Учитывайте `prefers-reduced-motion`
- Соблюдайте семантическую разметку
- Обеспечьте keyboard navigation

## GitHub и Деплой

### GitHub Pages
- **Основная ветка:** `main`
- **Путь деплоя:** `/` (корень)
- **Сборка:** `npm run build`
- **Результат:** `dist/`

### Правила Git
- Не коммитьте `node_modules/`, `dist/`, `.env`
- Используйте осмысленные commit messages
- Не храните секреты в коде

### GitHub Actions
Автоматический деплой на GitHub Pages будет настроен после инициализации.

## Что НЕ делать

❌ Не переписывайте рабочие компоненты без необходимости  
❌ Не удаляйте существующий функционал ради упрощения  
❌ Не создавайте фиктивную функциональность  
❌ Не размещайте все в одном файле  
❌ Не дублируйте код  
❌ Не добавляйте backend без необходимости  
❌ Не используйте Next.js (проект на Vite)  
❌ Не перегружайте сайт анимациями  
❌ Не игнорируйте TypeScript ошибки

## Дизайн-система

### Цвета
Основная палитра определена в `tailwind.config.js`:
- Primary: оттенки синего (blue-50 до blue-950)
- Используйте утилиты Tailwind для консистентности

### Типографика
- **Основной шрифт:** Inter
- **Заголовки:** Poppins
- Определены в `tailwind.config.js`

### Анимации
Предопределённые в Tailwind config:
- `animate-fade-in` - плавное появление
- `animate-slide-up` - скольжение вверх
- `animate-slide-down` - скольжение вниз
- `animate-scale-in` - масштабирование
